# martin-juul/dbal-duckdb

Doctrine DBAL 4 driver, platform and schema manager for [DuckDB](https://duckdb.org) 2.0, built on the native [ext-duckdb](https://github.com/martin-juul/php-duckdb) 2.0 extension.

Requires PHP 8.4+, ext-duckdb ^2.0 and doctrine/dbal ^4.5.

This package is under construction.
